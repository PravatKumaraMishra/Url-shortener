# URL Shortener

Placeholder repository for the URL shortener project. There is currently no application source or build configuration here.

## Implementations

The working source is maintained in separate repositories:

- [URL Shortener Backend](https://github.com/PravatKumaraMishra/Url-shortener-backend): Spring Boot API for authentication, shortening, redirects, and click analytics.
- [URL Shortener Frontend](https://github.com/PravatKumaraMishra/Url-shortener-frontend): React interface for managing links and viewing analytics.

Follow those repositories’ setup instructions to run the application. This repository has no standalone installation, start, or test command yet.
